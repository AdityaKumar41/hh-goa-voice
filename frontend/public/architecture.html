VOICE RAG PLATFORM / PRODUCTION ARCHITECTURE

Evidence, from voice to verified answer.

A complete view of the public frontend, Railway API, guarded research harness, hosted providers, vector index, and operational data flow.

INPUT

Voice is transcribed by ElevenLabs; typed queries can use the same guarded pipeline.

RETRIEVAL

Multilingual E5 embeddings and lexical matching search the promoted Qdrant alias.

VERIFICATION

Answers are accepted only after citation and evidence-overlap checks.

OPERATIONS

Versioned index builds validate before atomic promotion; PostgreSQL stores traces and metadata.
