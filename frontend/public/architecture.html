How the platform works.

Three readable views of the production system: how a request is answered, how knowledge is indexed, and how releases are observed.

01

Serving path — one request

Every voice and text query goes through the same guarded research harness. The final answer must be supported by retrieved evidence.

flowchart TD
  USER[User\nvoice or text] --> WEB[Vercel\nReact frontend]
  WEB --> API[Railway\nFastAPI API]
  API --> INPUT{Voice input?}
  INPUT -->|yes| STT[ElevenLabs\nspeech to text]
  INPUT -->|no| GUARD[QueryGuard]
  STT --> GUARD
  GUARD --> HARNESS[ResearchHarness\n1. guard  2. retrieve  3. answer  4. validate]
  HARNESS --> RETRIEVE[Hybrid retrieval\ndense + lexical]
  RETRIEVE --> EMBED[Multilingual E5\nquery embedding]
  EMBED --> QDRANT[(Qdrant\nvoice_rag_active)]
  QDRANT --> CONTEXT[Evidence context\nscore floor + budget]
  CONTEXT --> MODE{Answer mode}
  MODE -->|fast| FAST[Local extractive\nanswer]
  MODE -->|normal| LLM[OpenCode\nhosted generator]
  FAST --> CHECK[Grounding check\ncitations + overlap]
  LLM --> CHECK
  CHECK --> RESPONSE[Grounded JSON\nor SSE response]
  RESPONSE --> WEB

Knowledge path — build and promote

03

Operations — traces to release

This is the platform’s operational memory and LLMOps loop. It does not represent personal chat memory.

flowchart TD
  REQUEST[ResearchHarness\ncompleted request] --> TRACE[TraceSink\nprivacy-safe JSONL]
  TRACE --> POSTGRES[(Supabase PostgreSQL\nquery traces + index metadata)]
  POSTGRES --> EVAL[Evaluation suite\nlatency + refusal + grounding]
  EVAL --> RELEASE[Release record\nmodel / prompt / index version]
  RELEASE --> INDEX[Index worker\nnext version]
  TOOLS[Optional read-only tools\nJina Reader / Firecrawl] -.-> REQUEST
  MEMORY[Memory boundary\nno personal conversational memory in v1\nshared RAG knowledge only] -.-> REQUEST

MEMORY

Qdrant is retrieval memory.

It stores the shared indexed corpus, not a user’s private conversation.

OPERATIONS

PostgreSQL is the record.

It stores query traces and ingestion/index metadata.

TOOLS

External research is read-only.

Optional tools can supply context; they cannot write platform state.

Boundary to remember

The current release is stateless at the conversation layer. It answers from the versioned shared corpus, records operational traces, and does not claim to implement personal long-term memory.
